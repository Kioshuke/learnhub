1. Nhập đề

Dán văn bản, tải .docx (tự parse), tải .json, hoặc nạp đề mẫu. Dán JSON trực tiếp vào ô này cũng được — hệ thống tự nhận dạng.

2. Dữ liệu JSON & Xem trước

🧾 Cửa sổ dữ liệu JSON sửa tay → bên phải tự render
👁️ Cửa sổ xem trước
Chưa có đề. Ở bước 1 bấm "Đọc text → JSON" hoặc tạo JSON mẫu.

3. Rà soát & Xuất bản

Xem lại số câu hỏi, tóm tắt chỉnh sửa/thiết lập đề. Bấm 🚀 Xuất bản đề để cập nhật/đăng tải đề.
